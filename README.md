# 跨域測試工具

🌐 CORS Test Tool - 快速測試跨域請求是否成功

## 🌐 網站網址
https://lance70176.github.io/cors-test-tool/

## ✨ 功能特色

- 🔧 **多種 HTTP 方法** - 支援 GET/POST/PUT/DELETE
- ⚡ **即時測試** - 快速發送請求並顯示結果
- 📊 **詳細資訊** - 狀態碼、耗時、回應內容
- 🎯 **CORS 檢測** - 明確區分成功與 CORS 錯誤
- 📜 **測試歷史** - 自動儲存最近 10 筆測試記錄
- 💾 **LocalStorage** - 歷史記錄儲存在本地

## 🚀 使用方法

1. 選擇 HTTP 方法（GET/POST/PUT/DELETE）
2. 輸入目標網址
3. 點擊「發送跨域請求」按鈕
4. 查看測試結果

## 📋 結果說明

| 狀態 | 說明 |
|------|------|
| ✅ 請求成功 | CORS 沒有限制，成功收到回應 |
| ❌ CORS 錯誤 | 瀏覽器攔截了跨域請求，CORS 未正確配置 |
| ❌ HTTP 錯誤 | 伺服器回傳了錯誤狀態碼 |

## 🛡️ 隱私說明

- 純前端測試，所有請求由瀏覽器直接發送
- 測試歷史僅儲存在你的瀏覽器 localStorage
- 不會傳送到任何第三方伺服器
